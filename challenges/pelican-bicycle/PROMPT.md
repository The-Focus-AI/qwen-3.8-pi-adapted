Create an **animated SVG** in this working directory: a pelican riding a bicycle.

Requirements:

1. Single file `pelican-bicycle.svg` (SVG only — no HTML wrapper required).
2. The pelican should be recognizably a pelican (beak/pouch, body, wings or suggestion of wings).
3. The bicycle should have two wheels, a frame, and a place the pelican sits.
4. Use SMIL and/or CSS `@keyframes` inside the SVG so something clearly moves (wheels rotating, pedaling legs, bobbing body, scrolling ground, etc.). Prefer a looping animation.
5. Keep it self-contained (no external images or fonts). ViewBox sized for easy preview (e.g. ~800×600).
6. After writing the file, briefly note how to open it (e.g. open in a browser).

Verify by writing the file and confirming it is valid-ish SVG (starts with `<svg`, contains an animation element or `<style>` with `@keyframes`).
